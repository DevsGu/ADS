# Trabalho de Teste e Qualidade de Software

> Este projeto tem como objetivo identificar e refatorar **Code Smells** no repositório `tqds-mesw-les`, utilizando métricas de qualidade de software para guiar as melhorias na estrutura e manutenibilidade do código.

---

### 🛠️ Ferramentas Utilizadas

- **Análise de Métricas:** CodeMR
- **IDE:** Eclipse
- **Linguagem & Framework:** Java / Spring Boot
- **Banco de Dados:** pgAdmin (PostgreSQL)
- **Suporte de IA:** Gemini Flash Free
