# 📁 Documentação do Projeto: Teste e Qualidade de Software

> Bem-vindo à pasta de documentação do repositório **`tqds-mesw-les`**.

Aqui você verá todo o acompanhamento detalhado referente às etapas de análise de métricas, identificação de *Code Smells*, aplicação de refatorações de código e o uso direcionado de Inteligência Artificial para apoio às decisões técnicas.

## 📄 Conteúdo desta Pasta

Esta pasta reúne os relatórios detalhados do projeto:

   - Mapeamento das classes e métodos analisados.
   - Diagnóstico dos problemas e *Code Smells* identificados através do **CodeMR**.
   - Comparativo de métricas de qualidade (**Antes vs. Depois**).
   - Identificação dos *Commits* referentes a cada refatoração.

2. **[🤖 Registro do Uso da Inteligência Artificial](./02-uso-da-ia.md)**
   - Registros das interações e prompts submetidos ao **Gemini Flash Free**.
   - Resumo das sugestões geradas pela IA.
   - Registro da decisão tomada pela dupla (*Aceito*, *Alterado* ou *Rejeitado*).
   - Justificativas técnicas para cada tomada de decisão.
